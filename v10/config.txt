
=====================================================================
KORAK 1 | FAJL: semantic.y | AKCIJA: IZMIJENITI
MJESTO: sekcija deklaracija tokena, deklaracija _DIRECTION
---------------------------------------------------------------------
STARO:
%token _DIRECTION
NOVO:
%token <i> _DIRECTION

Ako vec pise %token <i> _DIRECTION, ne mijenjati tu liniju.
=====================================================================

=====================================================================
KORAK 2 | FAJL: semantic.l | AKCIJA: PROVJERITI / IZMIJENITI
MJESTO: pravila za rasti_rasti i pada_pada, prije pravila za _ID
---------------------------------------------------------------------
"rasti_rasti"        { yylval.i = 1; return _DIRECTION; }
"pada_pada"          { yylval.i = 0; return _DIRECTION; }
=====================================================================

=====================================================================
KORAK 3 | FAJL: semantic.y | AKCIJA: ZAMIJENITI
MJESTO: cijelo pravilo direction_statement, od direction_statement do njegovog ;
---------------------------------------------------------------------
STARO:
Postojece pravilo direction_statement sa pogresnim $4 i $6.

NOVO:
direction_statement
  : _DIRECTION _ID
      {
        if(lookup_symbol($2, VAR|PAR) == NO_INDEX)
          err("'%s' undeclared", $2);
      }
    _KRAJ literal _POCETAK literal
      {
        if(get_type($5) != get_type($7))
          err("incompatible types in direction statement");
        if($1 == 1 && atoi(get_name($7)) >= atoi(get_name($5)))
          err("start literal must be less than end literal");
        if($1 == 0 && atoi(get_name($7)) <= atoi(get_name($5)))
          err("start literal must be greater than end literal");
      }
    _IZVRSI statement
  ;
=====================================================================

KONTROLNA LISTA
[ ] _DIRECTION je deklarisan samo jednom, kao %token <i> _DIRECTION.
[ ] Oba smjera postavljaju yylval.i u semantic.l.
[ ] $1=_DIRECTION, $2=_ID, $3=akcija, $4=_KRAJ, $5=literal.
[ ] $6=_POCETAK, $7=literal, $8=akcija, $9=_IZVRSI, $10=statement.
[ ] U provjerama tipova i vrijednosti koriste se $5 i $7, ne $4 i $6.
[ ] direction_statement je ukljucen u statement.
[ ] Pokrenuti make; rezultat kompajliranja nije ovdje potvrdjen
